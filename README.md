# 무선설비기사 필기·실기 Pro

App-specific support and study website from RushLabs, in Korean and English. The separate Android Pro app is not yet publicly available; no download CTA is enabled.

Static HTML/CSS and original verified app screenshots. No JavaScript, analytics or third-party tracking. Build: `python3 scripts/check_site.py` checks the committed static pages. Deployment uses GitHub Pages Actions.
